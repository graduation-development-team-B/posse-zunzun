Web Push ローカルテスト

①はブラウザーの通知表示、②はPushサービスを経由した受信を確認します。アプリと同じサービスワーカーを使用します。Supabase・Cron・学習済み判定はこのテストに含みません。

Chromeなどの通常のタブで開いてください。スマホ表示用の拡張機能やiframe内での実行は避けてください。

macOSのChrome 152以降で左側のChromeアイコンもアプリのアイコンにするには、このページをPWAとしてインストールして開き、macOS側でもアプリの通知を許可してください。通常のタブではChromeのアイコンになります。

インストールしてアプリとして開いた後、通知を許可すると「システム設定 → 通知 → POSSEずんずん 通知テスト」で表示方法などを管理できます。



通知のバナーが見えない場合は、OSの通知センター・Chromeの通知設定・集中モードも確認してください。テスト終了後はターミナルでCtrl+Cを押します。
