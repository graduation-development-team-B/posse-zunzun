# 移行前デザインの復元

2026-10-07。ユーザーの「デザインは移行前のまま、データだけ移行する」という指定に合わせ、移行前バックアップの画面構成へ戻した。

## 復元した画面

- ホーム：熱中くんと吹き出し、連続日数、週の記録、レベル・XP、次の問題、見直し、フェーズのタイムライン。
- 記録：キャラクター、進化の道のり、3つの統計、チケット枠、当月カレンダー、バッジ。
- 問題設定：問題数の切り替え、3つの出題タイプのカード、問題の見本、下部の開始ボタン。
- 選択問題：吹き出し、番号付きの選択肢、選択・正誤の配色、元のフィードバックパネル。
- 操作問題：暗色のコード枠、点線の配置枠、オレンジのブロック、候補、戻す・はずす・ヒント、プレビュー枠。
- 完了：キャラクター、ごほうびの内訳、受け取り演出とXPアニメーション、記録を見る枠。

キャラクター画像、配色定数、共通UI、ボタン、下部ナビ、見出しなどは移行前のファイルとの比較で変更なし（38ファイルを確認）。各画面の元のStyleSheet定義を保存し、8画面・部品の回帰検査を追加した。追加形式の部品は別のスタイルとして最小限に定義する。

## 実データへの接続

既存82問、問題ID・正答・解説・改訂番号、作問フローの正本を維持した。採点、実行、保存、セッション復元の処理も維持し、画面へ渡す表示データを`src/lib/progress/presentation.ts`で組み立てる。

カレンダー・連続日数・問題数・XP・見直し・達成数・バッジは実際の回答から表示する。レベル表示は100 XP単位。XP獲得ルールは回答5点、正解追加5点のまま。ごほうびボタンは保存済みのXPを再加算せず、元の受け取り演出を表示する。

タイムラインの「まだ」の色は元の表現を使うが、教材一覧からはすべての公開単元を選べる。問題の件数・文の長さ・記録の値が変わるため、表示内容に伴う改行や高さは固定モックと異なる。

## 新しい形式に必要な差分

元の外観の中へ、HTMLの実プレビュー、Consoleの実行結果、Gitの仮想ログを表示する。実行結果を確認してから確定するため、プレビュー枠の見出しに小さな「実行する」を配置した。HTMLは実際のコードを表示するため、出力自体は元の固定サンプルとは異なる。候補の長いコードは枠内で折り返す。

選択問題のコード表示・ヒント、解説の出典表示を追加。問題設定のConsole・Gitの名称と見本は、その形式に合わせた内容へ差し替えた。チケット機能は未実装なので、元の枠を維持し「準備中」と表示する。教材の出典は該当見出しを示すテキストであり、未実装の教材ビューへのリンクではない。

## 確認

- `typecheck`、`lint`、`test:content`（97件）、`test:ui`（8件）、Web静的ビルド。
- 移行前バックアップを別のローカルサーバーで開き、復元した画面と比較。スマホ幅390pxでもホームを確認。
- 選択問題3問（正解・誤答・ヒント利用）から完了まで、25 XPの内訳と受け取り表示を確認。
- 再読み込み後に回答履歴・XP・見直し候補・進捗が残ることを確認。
- HTMLブロックを並べ、実プレビューと正解を確認。
- Consoleの候補を選び、350の実出力と正解を確認。
- Gitの`git commit -m "自己紹介を更新"`の仮想実行と正解を確認。

Native実機での見た目は未検証。HTML/Console実行は従来どおりWeb版のみ。クイズの内容は作り直していない。
